# 低代码平台（仿Dify）- 产品需求文档

## 概述
- **Summary**: 构建一个基于Python的低代码平台，提供可视化的工作流编辑器，支持节点拖拽、连接、配置，能够生成并执行Python代码，实现数据在节点间的联动流转，最终输出执行结果。后端采用Python UV环境，服务监听在 0.0.0.0:2222。
- **Purpose**: 降低Python自动化任务和数据处理流程的开发门槛，通过可视化拖拽的方式快速构建逻辑流程，自动生成可执行的Python代码并提供实时执行反馈。
- **Target Users**: 数据分析师、自动化测试工程师、Python初学者、需要快速构建数据处理/自动化脚本的开发者。

## Goals
- 提供一个类Dify的可视化工作流编辑界面，支持节点的添加、拖拽、连接和删除。
- 定义一套可扩展的节点系统，内置常用的Python代码执行、数据处理、条件分支、循环、输入输出等基础节点。
- 实现工作流的解析、生成Python代码、并在沙箱环境中安全执行的能力。
- 支持节点间的参数传递（联动），确保数据流在工作流中正确流转。
- 提供工作流的保存、加载、导出Python代码功能。
- 后端服务使用Python UV管理依赖，绑定端口 `0.0.0.0:2222`。
- 配置标准的 .gitignore 文件。

## Non-Goals (Out of Scope)
- 不实现复杂的权限管理和多用户协作系统（V1版本为单用户本地工具）。
- 不实现企业级的高可用、分布式部署架构（V1版本为单进程服务）。
- 不提供代码的在线调试功能（断点、步进等）。
- 不集成第三方AI大模型API（仅专注于代码生成与执行的基础平台）。

## Background & Context
- 低代码平台是当前开发工具的热点方向，Dify在LLM应用编排领域取得了成功。本项目旨在构建一个类似的、但专注于通用Python代码逻辑编排的工具。
- Python UV是新一代的Python包管理工具，速度快、体验好，适合作为新项目的依赖管理方案。
- 项目将采用前后端分离的架构，后端提供API服务，前端提供交互界面。

## Functional Requirements
- **FR-1**: 工作流可视化编辑器
  - 用户可以在浏览器中打开编辑器界面。
  - 用户可以从组件库拖拽节点到画布中。
  - 用户可以通过拖拽调整节点在画布中的位置。
  - 用户可以点击选中节点，查看和编辑节点属性。
  - 用户可以通过连线将一个节点的输出连接到另一个节点的输入。
  - 用户可以删除节点和连线。
  - 用户可以保存当前画布上的工作流到后端。
  - 用户可以加载已保存的工作流到画布。

- **FR-2**: 节点系统
  - 定义标准化的节点接口：包含输入参数、输出参数、节点类型、执行逻辑（或代码模板）。
  - 内置 **Start节点**：工作流入口，可定义初始输入参数。
  - 内置 **End节点**：工作流出口，用于收集最终输出。
  - 内置 **Python Code节点**：允许用户编写自定义Python代码片段，定义输入变量并返回输出。
  - 内置 **Condition节点**：根据条件表达式的布尔值决定流程走向（分支）。
  - 内置 **Loop节点**：实现简单的循环逻辑（如遍历列表）。
  - 节点配置支持JSON Schema定义的参数表单（输入框、下拉框等）。

- **FR-3**: 代码生成与执行引擎
  - 后端能够接收前端传来的工作流JSON数据。
  - 后端解析工作流的拓扑结构（DAG），确定节点执行顺序。
  - 后端根据节点类型和配置，生成完整的、可执行的Python脚本。
  - 后端在隔离的沙箱环境中执行生成的Python代码。
  - 执行时，支持节点间的数据传递（上一个节点的输出作为下一个节点的输入）。
  - 捕获执行过程中的标准输出(stdout)、标准错误(stderr)和异常。
  - 返回执行结果（成功/失败状态、返回数据、日志输出）给前端。

- **FR-4**: 工作流管理
  - 提供API用于创建、读取、更新、删除(CRUD)工作流定义。
  - 工作流定义持久化存储（V1使用文件系统JSON存储）。
  - 提供导出功能，允许将工作流导出为独立的 `.py` 文件。

- **FR-5**: 项目基础设施
  - 使用 **Python UV** 初始化项目，管理虚拟环境和依赖。
  - 配置 **.gitignore** 文件，排除虚拟环境、日志文件、临时文件等。
  - 后端服务启动时绑定地址 `0.0.0.0`，端口 `2222`。

## Non-Functional Requirements
- **NFR-1**: 安全性
  - 代码执行必须在严格受限的沙箱环境中运行，禁止执行危险的系统操作（如删除文件、网络访问等），V1至少应实现基础的危险函数拦截或提示。
  - API接口应具备基础的输入验证，防止恶意数据注入。
- **NFR-2**: 可扩展性
  - 节点系统设计应具备插件化扩展能力，便于后续添加新的节点类型。
  - 前后端代码结构清晰，模块化。
- **NFR-3**: 易用性
  - 前端界面简洁直观，操作流畅。
  - 错误信息提示清晰，便于定位问题。
  - 代码生成风格规范，可读性好。
- **NFR-4**: 性能
  - 简单工作流的代码生成和执行响应时间应小于2秒。

## Constraints
- **Technical**: 后端开发语言为 Python 3.10+，使用 UV 作为包管理器。前端使用现代Web技术栈（待定，建议React+TypeScript或Vue3）。
- **Business**: V1版本为MVP版本，核心聚焦于"拖拽-生成-执行"的闭环。
- **Dependencies**: Flask/FastAPI (后端框架), UV, 代码执行沙箱库 (如 RestrictedPython 或自定义沙箱)。

## Assumptions
- 假设用户具备基础的Python语法知识，能够理解节点配置中的代码逻辑。
- 假设用户在本地环境运行此平台，不需要严格的多租户隔离。
- 假设前端可以处理复杂的SVG/Canvas绘图逻辑来实现连线功能。

## Acceptance Criteria

### AC-1: 项目初始化与基础设施
- **Given**: 开发环境已安装Python UV
- **When**: 执行项目初始化命令
- **Then**: 
  - 项目目录下包含 `pyproject.toml` 和 `uv.lock` 文件
  - 根目录包含 `.gitignore` 文件，且忽略规则符合Python项目标准
  - 运行启动命令后，服务监听在 `0.0.0.0:2222`
- **Verification**: `programmatic`

### AC-2: 工作流编辑器基础操作
- **Given**: 用户已打开浏览器并访问平台首页
- **When**: 
  1. 从左侧组件库拖拽一个 "Start" 节点和一个 "Python Code" 节点到画布
  2. 点击 "Python Code" 节点，修改其代码内容为 `print("Hello")`
  3. 点击保存按钮
- **Then**: 
  - 画布上清晰显示两个节点及其位置
  - 属性面板显示 "Python Code" 节点的代码内容
  - 后端返回保存成功的响应，数据库/文件中存在新的工作流记录
- **Verification**: `human-judgment` (界面检查) + `programmatic` (API响应检查)

### AC-3: 节点连线与联动配置
- **Given**: 画布上存在 A 节点（输出变量 `x`）和 B 节点（输入参数 `y`）
- **When**: 从 A 节点的输出点拖拽一条线连接到 B 节点的输入点
- **Then**: 
  - 画布上显示一条连接两个节点的曲线
  - B 节点的参数 `y` 被标记为 "已连接" 或自动填充为引用 `A.x`
- **Verification**: `human-judgment`

### AC-4: 简单工作流执行
- **Given**: 
  - 画布上有 Start 节点 (定义输入 `name: "World"`) -> Python Code 节点 (代码: `return f"Hello {name}"`) -> End 节点
  - 节点连接正确
- **When**: 点击 "Run" 按钮
- **Then**: 
  - 前端显示执行中状态
  - 执行完成后，返回结果面板显示 "Hello World"
  - 执行日志显示 "执行成功"
- **Verification**: `programmatic` (检查API返回的result字段)

### AC-5: 代码导出功能
- **Given**: 已保存的工作流
- **When**: 点击 "Export Python" 按钮
- **Then**: 
  - 浏览器触发下载一个 `.py` 文件
  - 文件内容包含根据工作流逻辑生成的完整、可独立运行的Python代码
- **Verification**: `human-judgment` (代码可读性检查) + `programmatic` (本地运行导出的代码验证结果)

### AC-6: 执行错误处理
- **Given**: 画布上有一个 Python Code 节点，代码内容为 `1 / 0` (除零错误)
- **When**: 运行工作流
- **Then**: 
  - 前端显示执行失败状态
  - 错误信息中包含 `ZeroDivisionError` 或相关堆栈信息
- **Verification**: `programmatic`

- **代码执行**：RestrictedPython 实现安全沙箱
- **数据存储**：文件系统 JSON 存储 (工作流定义)
