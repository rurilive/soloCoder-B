# 问卷调查平台 - Product Requirement Document

## Overview
- **Summary**: 开发一个基于 Python Flask + uv + Jinja2 的问卷调查平台，支持拖拽式问卷编辑、用户角色权限管理、防刷票机制以及完善的数据统计功能。
- **Purpose**: 为企业或个人提供一个功能完整、安全可靠的在线问卷调查工具，支持问卷设计、发布、收集、统计全流程。
- **Target Users**: 
  - 问卷管理员（创建和管理问卷）
  - 普通用户（参与问卷调查）
  - 系统管理员（管理用户、角色、权限）

## Goals
- 实现拖拽式问卷编辑器，支持多种题型
- 建立完善的用户、角色、用户组权限管理系统
- 实现多重防刷票机制，确保问卷数据真实性
- 提供直观的统计分析页面，支持数据可视化
- 保证系统安全性和用户体验

## Non-Goals (Out of Scope)
- 不开发移动端 App，仅提供 Web 界面
- 不集成第三方登录（如微信、QQ），仅使用本地账号系统
- 不提供问卷付费功能
- 不实现实时协作编辑
- 不支持大规模数据分析和机器学习预测

## Background & Context
- 当前目录为空项目，需从零开始构建
- 使用 Python Flask 作为后端框架
- 使用 uv 作为 Python 包管理器
- 使用 Jinja2 作为模板引擎
- 使用 SQLite 作为数据库
- 前端使用原生 JavaScript 实现拖拽功能

## Functional Requirements

### 用户与权限系统
- **FR-1**: 用户注册、登录、登出功能
- **FR-2**: 用户角色管理（超级管理员、问卷管理员、普通用户）
- **FR-3**: 用户组管理，支持按组分配权限
- **FR-4**: 基于 RBAC 的权限控制机制
- **FR-5**: 用户个人资料管理

### 问卷管理系统
- **FR-6**: 创建新问卷、编辑、复制、删除问卷
- **FR-7**: 问卷状态管理（草稿、发布、暂停、结束）
- **FR-8**: 问卷发布设置（有效期、访问密码、开始/结束时间）
- **FR-9**: 问卷权限控制（公开、仅登录用户、仅指定用户组）

### 拖拽式问卷编辑器
- **FR-10**: 支持多种题型：单选题、多选题、填空题、评分题、量表题、日期题、文件上传
- **FR-11**: 拖拽方式添加、排序、删除题目
- **FR-12**: 题目必填/可选设置
- **FR-13**: 题目逻辑跳转（根据答案跳转到指定题目）
- **FR-14**: 分页支持（长问卷可分多页）
- **FR-15**: 问卷预览功能

### 问卷作答系统
- **FR-16**: 问卷浏览和作答界面
- **FR-17**: 作答进度保存（支持中途退出继续作答）
- **FR-18**: 提交答案功能
- **FR-19**: 作答完成反馈页面

### 防刷票机制
- **FR-20**: IP 限制（同一 IP 限制作答次数）
- **FR-21**: Cookie 跟踪（同一设备限制作答次数）
- **FR-22**: 验证码验证（防止机器人刷票）
- **FR-23**: 登录用户限制（必须登录才能作答）
- **FR-24**: 异常行为检测（短时间大量相同答案）

### 统计分析系统
- **FR-25**: 作答人数统计
- **FR-26**: 各题目答案统计（单选/多选饼图、柱状图）
- **FR-27**: 评分题/量表题平均分统计
- **FR-28**: 填空题关键词分析（词频统计）
- **FR-29**: 跨题目交叉分析
- **FR-30**: 作答时间分布统计
- **FR-31**: 数据导出（CSV/Excel）

## Non-Functional Requirements

- **NFR-1**: 安全性
  - 密码使用 bcrypt 加密存储
  - 防止 SQL 注入（使用参数化查询）
  - 防止 XSS 攻击（输出转义）
  - 防止 CSRF 攻击（使用 CSRF Token）
  - Session 安全配置

- **NFR-2**: 性能
  - 页面加载时间 < 3秒
  - API 响应时间 < 500ms
  - 支持同时至少 100 个并发用户

- **NFR-3**: 可维护性
  - 代码结构清晰，模块化设计
  - 数据库设计符合第三范式
  - 关键功能有注释说明

- **NFR-4**: 用户体验
  - 响应式设计，支持 PC 和移动端
  - 界面简洁直观
  - 操作有明确反馈

## Constraints
- **Technical**: 
  - 后端：Python 3.10+, Flask 2.0+
  - 包管理：uv
  - 模板引擎：Jinja2
  - 数据库：SQLite
  - 前端：原生 JavaScript, HTML5, CSS3
  - 不允许使用 Vue/React 等前端框架

- **Business**:
  - 单实例部署，不考虑分布式
  - 文件存储使用本地文件系统

- **Dependencies**:
  - Flask-Login（用户认证）
  - Flask-WTF（表单处理和 CSRF）
  - Flask-SQLAlchemy（ORM）
  - Flask-Migrate（数据库迁移）
  - bcrypt（密码加密）
  - Pillow（图片验证码）
  - openpyxl/pandas（Excel 导出）

## Assumptions
- 用户能够使用现代浏览器（Chrome、Firefox、Safari、Edge）
- 服务端具有基本的网络连接
- 问卷数据量在 SQLite 可承受范围内（单表 < 100万行）
- 用户具有基本的计算机操作能力

## Acceptance Criteria

### AC-1: 用户注册登录
- **Given**: 用户未登录
- **When**: 用户访问注册页面，填写有效信息并提交
- **Then**: 用户账号创建成功，可使用该账号登录
- **Verification**: `programmatic`

### AC-2: 角色权限控制
- **Given**: 系统存在不同角色的用户
- **When**: 普通用户尝试访问管理员功能
- **Then**: 系统拒绝访问，返回无权限提示
- **Verification**: `programmatic`

### AC-3: 拖拽创建问卷
- **Given**: 用户是问卷管理员
- **When**: 用户在编辑器中拖拽题目组件到问卷区域
- **Then**: 题目成功添加，可编辑题目内容和选项
- **Verification**: `human-judgment`

### AC-4: 多种题型支持
- **Given**: 用户正在编辑问卷
- **When**: 用户添加不同类型的题目
- **Then**: 每种题型都能正确显示、编辑和保存
- **Verification**: `programmatic`

### AC-5: 问卷发布与作答
- **Given**: 问卷已发布且用户有权访问
- **When**: 用户访问问卷链接并作答提交
- **Then**: 答案成功保存到数据库
- **Verification**: `programmatic`

### AC-6: IP 防刷票
- **Given**: 问卷设置了每人限答 1 次
- **When**: 同一 IP 多次尝试提交同一问卷
- **Then**: 第二次及以后提交被拒绝
- **Verification**: `programmatic`

### AC-7: 验证码防刷
- **Given**: 问卷启用了验证码
- **When**: 用户作答时输入错误的验证码
- **Then**: 提交被拒绝，提示验证码错误
- **Verification**: `programmatic`

### AC-8: 统计数据展示
- **Given**: 问卷已有有效作答数据
- **When**: 管理员查看统计页面
- **Then**: 各题目统计数据正确显示，图表正确渲染
- **Verification**: `human-judgment`

### AC-9: 数据导出
- **Given**: 问卷已有作答数据
- **When**: 管理员点击导出按钮
- **Then**: CSV/Excel 文件成功下载，数据完整
- **Verification**: `programmatic`

### AC-10: 安全防护
- **Given**: 系统正常运行
- **When**: 尝试 SQL 注入、XSS、CSRF 攻击
- **Then**: 攻击被拦截，系统不受影响
- **Verification**: `programmatic`
